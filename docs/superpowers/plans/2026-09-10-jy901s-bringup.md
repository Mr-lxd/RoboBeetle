# JY901S IMU Bring-Up Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** Add a listen-only JY901S receive path from USART3/PB11 through one-byte interrupt RX and an 11-byte pure-C parser into internal Acc/Gyro/Angle state, with diagnostics and no sensor configuration writes.

**Architecture:** Keep USART1 on its existing 128-byte-storage, blocking-transmit, and Protocol V2 host-link path. The current hardware evidence uses DAP UART/COM13; the legacy-named APC220 profile is not current hardware evidence. Generalize only pure ring-buffer storage ownership so USART1 retains its 127-byte effective capacity while a new HAL-aware JY901S transport owns an independent 256-byte storage and foreground re-arm maintenance. Keep protocol decoding, engineering-unit conversion, Mag-known-ignore handling, and resynchronization in a HAL-independent parser; app_main only drains the transport, records valid-frame time, and exposes read-only bring-up accessors.

**Tech Stack:** C11, STM32F407 HAL/CubeMX-generated C, host GCC with -Wall -Wextra -Werror, CMake/Ninja where the ARM toolchain exists, and the existing manual Firmware tests plus Console CTest.

Implement ring_buffer.c with fail-closed configuration and the same one-slot-reserved semantics:

~~~c
#include "ring_buffer.h"

static bool ring_buffer_is_configured(const ring_buffer_t *buffer)
{
    return (buffer != NULL) &&
           (buffer->data != NULL) &&
           (buffer->storage_size >= 2U);
}

void ring_buffer_init(
    ring_buffer_t *buffer,
    uint8_t *storage,
    uint16_t storage_size)
{
    if (buffer == NULL)
    {
        return;
    }

    buffer->head = 0U;
    buffer->tail = 0U;

    if ((storage == NULL) || (storage_size < 2U))
    {
        buffer->data = NULL;
        buffer->storage_size = 0U;
        return;
    }

    buffer->data = storage;
    buffer->storage_size = storage_size;
}

bool ring_buffer_push(ring_buffer_t *buffer, uint8_t byte)
{
    if (!ring_buffer_is_configured(buffer))
    {
        return false;
    }

    uint16_t next = (uint16_t)(buffer->head + 1U);
    if (next >= buffer->storage_size)
    {
        next = 0U;
    }

    if (next == buffer->tail)
    {
        return false;
    }

    buffer->data[buffer->head] = byte;
    buffer->head = next;
    return true;
}

bool ring_buffer_pop(ring_buffer_t *buffer, uint8_t *byte)
{
    if (!ring_buffer_is_configured(buffer) || (byte == NULL))
    {
        return false;
    }

    if (buffer->head == buffer->tail)
    {
        return false;
    }

    *byte = buffer->data[buffer->tail];
    ++buffer->tail;
    if (buffer->tail >= buffer->storage_size)
    {
        buffer->tail = 0U;
    }
    return true;
}
~~~

- [ ] **Step 4: Implement the fixed-length parser and resynchronization.**

Implement jy901s_parser.c with this signed little-endian helper and resynchronization helper:

~~~c
static int16_t decode_signed_le(
    const uint8_t frame[JY901S_FRAME_LENGTH],
    uint8_t offset)
{
    uint16_t raw = (uint16_t)frame[offset] |
                   (uint16_t)((uint16_t)frame[offset + 1U] << 8U);
    return (int16_t)raw;
}

static void resync_after_bad_candidate(jy901s_parser_t *parser)
{
    for (uint8_t index = 1U;
         index < parser->candidate_length;
         ++index)
    {
        if (parser->candidate[index] == JY901S_FRAME_HEADER)
        {
            uint8_t suffix_length =
                (uint8_t)(parser->candidate_length - index);
            memmove(
                parser->candidate,
                &parser->candidate[index],
                suffix_length);
            parser->candidate_length = suffix_length;
            ++parser->stats.header_count;
            return;
        }
    }
    parser->candidate_length = 0U;
}
~~~

The feed path ignores non-header idle bytes, increments header_count whenever a candidate begins or is retained by resynchronization, collects exactly 11 bytes, sums bytes 0 through 9 into uint16_t, and compares (uint8_t)sum with byte 10. On checksum failure it increments only checksum_error_count and calls resync_after_bad_candidate. On checksum success it increments valid_frame_count, clears candidate length, and applies:

- Type 0x51: offsets 2/4/6 with raw / 32768.0f * 16.0f, Acc fields/valid flag, acc_frame_count, and ACC event.
- Type 0x52: raw / 32768.0f * 2000.0f, Gyro fields/valid flag, gyro_frame_count, and GYRO event.
- Type 0x53: raw / 32768.0f * 180.0f, roll/pitch/yaw fields/valid flag, angle_frame_count, and ANGLE event.
- Type 0x54: no state update, mag_frame_count, and MAG_IGNORED event.
- Any other type: no supported-state update, unsupported_frame_count, and UNSUPPORTED event.

Use memset in init and memcpy in both getters after null checks. Do not include any HAL header or command/transmit code.

- [ ] **Step 4: Implement the transport with one-attempt foreground recovery.**

### Superseded pre-PR11 direct-callback sketch

The following original implementation sketch is retained for checkpoint
traceability only. It was superseded before PR #11 closeout because collapsing
`HAL_BUSY` and `HAL_ERROR` into one counter did not provide the required
diagnostic semantics or recovery state.

~~~c
/* Historical sketch — do not implement verbatim. */
static void try_rearm(void)
{
    diagnostics.rx_armed = false;
    diagnostics.rx_needs_rearm = true;

    if ((uart_handle != NULL) &&
        (HAL_UART_Receive_IT(uart_handle, &rx_byte, 1U) == HAL_OK))
    {
        diagnostics.rx_armed = true;
        diagnostics.rx_needs_rearm = false;
        return;
    }

    ++diagnostics.rx_rearm_failure_count;
}
~~~

The final implementation instead uses a 256-byte static storage array,
separate ring object, one-byte staging variable, stored UART handle, and
diagnostics. RX-complete and error callbacks only account for the event and
mark the transport pending. The private foreground helper makes one call only
when pending; it classifies `HAL_OK` as success, `HAL_BUSY` as deferred work,
and `HAL_ERROR`/other non-success statuses as hard failures. A generation
re-check keeps a callback/error event that arrives during the arm operation
from being cleared by a stale success transition.

~~~c
/* Final behavior summary; see jy901s_transport_stm32.c for the full code. */
if (rearm_is_pending) {
    generation = rx_rearm_generation;
    status = HAL_UART_Receive_IT(uart_handle, &rx_byte, 1U);
    if (status == HAL_OK && generation == rx_rearm_generation) {
        diagnostics.rx_armed = true;
        diagnostics.rx_needs_rearm = false;
    } else if (status == HAL_BUSY) {
        ++diagnostics.rx_rearm_deferred_count;
        /* Keep pending unless HAL reports an already-active receive. */
    } else if (status != HAL_OK) {
        ++diagnostics.rx_rearm_failure_count;
        /* Keep pending for the next foreground poll. */
    }
}
~~~

init zeroes diagnostics, initializes the 256-byte ring, stores the handle, and
calls the foreground-equivalent arm path once. `on_rx_complete` accepts only
`huart->Instance == USART3`, increments `rx_byte_count`, pushes the staging byte
and increments either `rx_buffer_push_count` or `rx_buffer_overflow_count`, then
marks the transport pending. It does no parsing, loops, blocking calls, or
transmit.

poll calls try_rearm once only when `rx_needs_rearm` is true or `rx_armed` is
false. pop increments rx_pop_count only after a successful ring pop.

on_error accepts only USART3, increments uart_error_count, checks huart->ErrorCode against HAL_UART_ERROR_ORE, HAL_UART_ERROR_FE, HAL_UART_ERROR_NE, HAL_UART_ERROR_PE, and HAL_UART_ERROR_DMA, increments each matching counter, marks recovery pending as required by the HAL receive state, and returns without calling HAL, parsing, or looping. USART1 callbacks are ignored by this module.
